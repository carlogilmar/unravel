## Unravel App

The goal of this app is build a system to help developers to read, understand and correct code generated by AI. The speed of development with AI is incredible, but now we're generating more code than the code we can understand, so we're losing agency of knowledge. 

Felienne Hermans explains how code is a cognitive activity that breaks into three parts: long-term memory, short-term memory and working memory. Code involve cognitive loads like understand the syntax, understand the logic abstraction and understand how the flow works. This parts are important to have agency and ownership of the code. 

AI is powerful, but we need to develop context tools to help us to maintain the ownership.

## Technical Requirements

This app will use Rust + Tauri + Svelte to develop a MacOs Desktop application

## Features

1. Directory Explorer: This app should begin by open an existing directory, the user should be able to search the directory and select it.
2. Once the use selected the code project, this project will use git version to see what files were changed. So the user will see the files changed in the working directory. 
3. The user will have the option to select every file to see the detail, he will see code file and we need to mark the new parts added only, so the user will see new code and he will have the opportunity to read line by line.
4. This first version will be optimized for elixir and python.
